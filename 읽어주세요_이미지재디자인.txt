■ 카톡 미리보기 이미지 재디자인 (HP-IN-MH4) ■

이번에 고친 것(파란 이미지 안):
 1) 카테고리 칩(안전/일반 등) 삭제
 2) 제목·본문이 화면 밖으로 잘리지 않도록 '자동 줄바꿈' 적용
 3) 흐려짐(페이드) 제거 → 하단 내용(줄들)까지 전부 보임
 4) 글자 블록을 카드 세로 '중앙'에 배치
 5) 내용이 길면 글자 크기를 자동으로 살짝 줄여 카드 안에 다 들어오게 함

설치: 이 ZIP 을 HP-IN-MH4 폴더에서 '압축 풀기'(덮어쓰기) → GitHub Desktop → Commit → Push

★ 반영 확인:
 - 이미지(og-image.png)는 이미 새 디자인입니다.
 - 문구를 바꾸실 땐 share/미리보기_만들기.html 로 편집 → [미리보기 내용 저장] → Push
   (카테고리 선택 항목은 없어졌습니다)
 - 카톡은 캐시가 있으니, Push 후 developers.kakao.com/tool/clear/og 에
   https://kinof2018-create.github.io/HP-IN-MH4/  넣고 [초기화] 후 붙여넣기.
