■ 특정이슈 '증빙자료 폴더' 자동연동 적용 (HP-IN-MH4) ■

[구성]
 1) facility.html                → 시설관리 유지보수 탭(교체본). '특정이슈증빙' 폴더를 자동으로 읽어옵니다.
 2) 특정이슈증빙/                 → 증빙파일을 올리는 폴더(신규). HPPK 'DOC 폴더'와 똑같은 방식입니다.

[설치 — 한 번만]
 이 ZIP 을 HP-IN-MH4 폴더에서 '압축 풀기'(덮어쓰기) → GitHub Desktop → Commit → Push

[증빙자료 올리는 법 — 매번]
 특정이슈증빙/ 폴더 안에 '관리번호'와 같은 이름의 하위폴더(예: TO-16)를 만들고
 그 안에 사진·PDF 를 넣은 뒤 → GitHub Desktop → Commit → Push
 → 1~2분 뒤 대시보드의 특정이슈 팝업/상세내역에서 '📎 증빙자료 보기'로 자동 표시됩니다.
 (자세한 규칙은 특정이슈증빙/읽어주세요_증빙자료_올리는법.txt 참고)

※ 이 방식은 엑셀에 경로를 적지 않아도 '폴더에 올리기만' 하면 자동 연동됩니다.
※ GitHub Pages(웹)에서 열었을 때 자동탐색이 동작합니다(HPPK DOC 폴더와 동일).
