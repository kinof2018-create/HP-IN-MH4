# 경영자 보고서 서류 이력 관리 · REPORT 폴더

대시보드의 **경영자 보고서 이력** 탭이 이 폴더를 자동으로 읽어 파일을 표시합니다.
GitHub 저장소 `kinof2018-create/HP-IN-MH4` 의 `main` 브랜치 최상위에 `REPORT/` 폴더를 올려 주세요.

## 폴더 규칙
```
REPORT/[프로젝트폴더]/[01_Draft | 02_Final | 03_Reference]/[버전]_[제목].확장자
REPORT/99_양식및표준/경영자보고서_표준템플릿_v1.0.pptx
```
- **01_Draft** : 작성·검토중 문서(v0.x, 수시 수정·백업)
- **02_Final** : 경영진 승인 완료본(v1.0 이상만 이동, 읽기 전용 권장)
- **03_Reference** : 보고서에 활용된 엑셀 기초 데이터·수집 자료 등
- 파일명에 `YYYY-MM-DD` 가 있으면 날짜가 함께 표시되고 최신순 정렬됩니다.
- 지원: pdf, pptx, docx, xlsx, png/jpg, hwp, txt, csv 등

## 대시보드 기능
- 프로젝트별 **변경 이력표**(버전/개정일자/개정내용/작성자/상태) 조회
- **문제점·이슈·확인사항·유의사항·진행사항** 트래킹(항목 추가/삭제, 상태 클릭 변경) — 이 브라우저에 저장
