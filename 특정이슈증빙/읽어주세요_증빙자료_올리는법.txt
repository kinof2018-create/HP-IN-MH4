■ 특정이슈 증빙자료 올리는 법 (HPPK 'DOC 폴더'와 동일 방식) ■

이 「특정이슈증빙」 폴더 안에, 설비의 '관리번호'와 똑같은 이름으로 하위 폴더를 만들고
그 안에 사진·PDF 등 증빙파일을 넣은 뒤 GitHub Desktop 에서 Push 하면,
시설관리 유지보수 탭의 특정이슈 팝업/상세내역에서 자동으로 연결되어 표시됩니다.
(엑셀에 경로를 따로 적지 않아도 됩니다. 폴더에 올리기만 하면 자동 연동)

─ 폴더 구조 예시 ─
  특정이슈증빙/
    ├─ TO-16/                 ← '관리번호'와 동일한 이름
    │    ├─ L8에러_사진.jpg
    │    └─ 점검보고서.pdf
    ├─ TO-24/
    │    └─ 레버파손.jpg
    └─ HR-08/
         └─ 균열사진.png

─ 규칙 ─
 1) 하위 폴더 이름 = 엑셀의 '관리번호' 와 똑같이 (예: TO-16, HR-08).
    (대소문자·띄어쓰기·하이픈(-)·언더바(_) 차이는 자동으로 무시하고 맞춰줍니다.)
 2) 넣을 수 있는 파일: 이미지(jpg·png·gif 등), PDF 등. 개수 제한 없음(여러 장 가능).
 3) 파일을 넣고 GitHub Desktop → Commit → Push → 1~2분 뒤 새로고침하면 반영.
 4) 이 안내 텍스트(.txt)와 .gitkeep 파일은 화면에 표시되지 않습니다.

※ 엑셀에 「특정이슈 증빙자료」 칸으로 직접 경로/웹주소를 적어도 함께 표시됩니다(선택).
