[중요] 지금 사장님 저장소의 index.html 안에는 Git '병합 충돌 표시'가
그대로 들어가 있었고(<<<<<<< , ======= , >>>>>>>), 그 안에 옛 제목이
남아 있어서 카톡에 그 문구가 계속 보였습니다.

이번 수정으로:
 1) index.html 의 충돌 표시를 깨끗이 정리했습니다(제목/설명 빈 값 1세트만 남김).
    → 카톡 카드의 이미지 아래 '문구'가 사라집니다.
    (맨 아래 도메인 kinof2018-create.github.io 한 줄은 카톡이 자동으로 붙이는
     부분이라 제거 불가입니다.)
 2) 파란 이미지 안의 글자를 전체적으로 더 크게 키웠습니다.
 3) ★재발 방지★: 앞으로 자동 생성(GitHub Action)이 index.html 을 건드리지
    않도록 바꿨습니다. (이미지 주소를 고정 → 자동 커밋과 사장님 Push 가
    부딪혀 생기던 '병합 충돌'이 다시 생기지 않습니다.)

설치(꼭 '덮어쓰기'):
 이 ZIP 을 HP-IN-MH4 폴더에서 '압축 풀기' → 덮어쓰기(예) →
 GitHub Desktop → Commit → Push
 → 1~2분 뒤 반영. 카톡은 캐시가 있으니
   developers.kakao.com/tool/clear/og 에
