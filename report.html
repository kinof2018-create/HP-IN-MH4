    프로젝트

      경영진 보고 이력 정리 GitHub 자동 연동

      프로젝트별 버전·변경이력·이슈를 추적하고, 관련 서류를 조회·업로드합니다.

      문서 관리 시스템

      ➕ 새 프로젝트 추가

      ＋ 등록을 누르면 GitHub에 프로젝트 파일이 만들어지고, Commit(저장)하면 모든 컴퓨터에서 이 프로젝트가 보입니다.

      ☁ 버튼을 누르면 GitHub 새 파일 등록 화면이 열립니다. 그 화면 맨 아래 Commit changes 를 누르면 모든 PC에 반영됩니다. (커밋 전에는 내 화면에서만 미리 보입니다.)

      ☁ GitHub 연결 (관리자)

      토큰을 연결하면 프로젝트 추가·삭제가 곧바로 GitHub에 저장되어 모든 PC에 반영됩니다. 토큰은 이 브라우저에만 저장됩니다.

      만드는 법: GitHub → 우측상단 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access에서 HP-IN-MH4 선택 → Permissions → Contents: Read and write → 발급된 토큰 문자열을 위에 붙여넣기.
      ⚠ 이 토큰은 저장소 쓰기 권한이 있으니 외부에 노출하지 마세요. (관리자 PC에서만 연결)
