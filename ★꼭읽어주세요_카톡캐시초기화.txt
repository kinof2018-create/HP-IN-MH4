 1) 빨간 박스 '제목/설명 문구' 제거
    - 원인: og:title 을 '비워두면' 카카오톡이 페이지 제목(<title>)으로 자동 대체해서
      "삼화당피앤티 통합 대시보드 · 시설관리 / HPPK..." 가 계속 나왔습니다.

      (맨 아래 도메인 kinof2018-create.github.io 한 줄은 카톡이 자동으로 붙이는 것이라
       기술적으로 제거가 불가능합니다.)
 2) 파란 이미지 글자 확대 — 서버 이미지는 '이미 확대'되어 있습니다.
    카톡에 작게 보였던 건 '카톡 캐시' 때문입니다. 아래 캐시 초기화를 꼭 하세요.

[설치]
 이 ZIP 을 HP-IN-MH4 폴더에서 '압축 풀기'(덮어쓰기) → GitHub Desktop → Commit → Push

[★★ 가장 중요 — 카톡 캐시 초기화 ★★]
 카카오톡은 미리보기를 한 번 저장(캐시)하면 계속 그걸 보여줍니다.
 Push 후 1~2분 뒤, 아래를 반드시 하세요:
  1. 인터넷에서  developers.kakao.com/tool/clear/og  접속
  2. 입력창에  https://kinof2018-create.github.io/HP-IN-MH4/  붙여넣기
  3. [초기화](캐시 삭제) 버튼 클릭
  4. 그 다음에 단톡방에 링크를 붙여넣으면 새 미리보기(공백 제목 + 확대 이미지)가 뜹니다.
 ※ 초기화를 안 하면 예전 카드가 계속 보입니다(파일을 아무리 바꿔도 소용없음).

포함 파일: index.html / og/generate.py / share/og-image.png
