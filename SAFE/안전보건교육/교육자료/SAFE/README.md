# SAFE — 안전보건관리 자료 폴더

대시보드 "안전보건관리" 탭이 이 폴더를 자동으로 읽어 화면에 표시합니다.

## 폴더 규칙
SAFE / <항목명> / <세부기능명> / [연도(선택)] / 파일
예) SAFE/위험성평가/위험성평가 실시/2026/2026-01-15_정기위험성평가_1공장.pdf

## 파일 이름(권장)
YYYY-MM-DD_문서명_대상.pdf   (날짜를 맨 앞에 → 화면에서 최신순 자동 정렬)

## 파일 형태
PDF 권장. 한글/워드/엑셀/사진은 PDF로 변환해 업로드.

## 올리는 법
- 대시보드 각 항목의 "＋GitHub에 자료 올리기" 버튼 → 해당 폴더 업로드 화면
- 또는 GitHub 웹(Add file→Upload files) / GitHub Desktop 으로 폴더에 넣고 Push

## 주의(개인정보)
건강진단 등 민감 개인정보는 공개 저장소 URL로 접근될 수 있습니다. 민감 자료는 비공개 저장소 등 별도 보관 권장.

## 참고
.gitkeep 은 빈 폴더 유지용 표시이며 화면에는 나타나지 않습니다.
