# ESG 심층 보고서 · 증빙자료 폴더 (ESG/)
(주)삼화당피앤티 통합 대시보드의 **ESG 심층 보고서 탭**이 이 폴더를 자동으로 읽어 화면에 표시합니다.
GitHub 저장소 `kinof2018-create/HP-IN-MH4` 의 `main` 브랜치 최상위에 `ESG/` 폴더 그대로 올려 주세요.

## 폴더 규칙
```
ESG/[영역]/[세부항목]/[연도]_[제목].확장자
```
- **영역**: `E`(환경) · `S`(사회) · `G`(지배구조) · `공통`(연간보고·대외제출 등)
- **세부항목**: 아래 목록의 폴더명을 그대로 사용 (새 폴더 추가도 가능)
- **파일명 예시**: `2025-09-24_ISO14001_인증서.pdf`, `2025_온실가스_인벤토리.xlsx`
  - 파일명에 `YYYY-MM-DD` 형식 날짜가 있으면 화면에 날짜가 함께 표시되고 최신순으로 정렬됩니다.
- 지원 형식: `pdf, png, jpg, jpeg, gif, webp, hwp, hwpx, doc, docx, xls, xlsx, ppt, pptx, tif, tiff`
  - `.hwp/.hwpx`는 브라우저에서 바로 열리지 않으므로 **PDF 변환본**을 함께 올리는 것을 권장합니다.

## 업로드 방법
1. 대시보드 **ESG 심층 보고서 탭 → 좌측 항목 선택 → “＋ GitHub에 자료 올리기”** 버튼을 누르면 해당 폴더의 업로드 화면으로 바로 이동합니다.
2. GitHub 로그인 후(저장소 쓰기 권한 필요) 파일을 끌어다 놓고 **Commit** 하면 됩니다.
3. 업로드가 완료되면 대시보드에서 새로고침 시 자동으로 목록에 나타납니다.

> ※ 현재는 GitHub 업로드 방식이며, 향후 대시보드에서 직접 업로드하는 기능으로 교체할 수 있도록 설계되어 있습니다.
